## Задача

Бинарная классификация физических лиц по уровню годового дохода (`<=50K` / `>50K`) на датасете [Adult](https://archive.ics.uci.edu/dataset/2/adult) (UCI, перепись населения США 1994 года, 48 842 записи) двумя моделями: **логистической регрессией** и **методом опорных векторов (SVC)**.

Решение: [`adult_income_logreg_svm.ipynb`](adult_income_logreg_svm.ipynb). Все ячейки выполнены, результаты видны без перезапуска.

## Что сделано

1. **Загрузка данных.** Объединены `adult.data` и `adult.test` из архива UCI (48 842 записи).
2. **Первичный анализ.**
   - Пропуски записаны в данных как `?` (`workclass`, `occupation`, `native-country`). Строки с пропусками (7,4%) удалены, заодно удалены 47 дубликатов, осталось 45 175 записей. Описаны альтернативные способы работы с пропусками, один из них (категория `Unknown`) проверен на практике.
   - Построены графики: баланс классов, возраст по классам дохода, доля высокого дохода по уровням образования, матрицы ошибок моделей.
   - Преобразования: удалены `education` (дублирует `education-num`) и `fnlwgt` (технический вес выборки), `sex` и целевая переменная закодированы в 0/1, шесть номинальных признаков переведены в one-hot кодирование. Получилось 80 признаков.
3. **Разделение** 80/20 со стратификацией (36 140 / 9 035 записей).
4. **Обучение** пайплайнов `StandardScaler → LogisticRegression` и `StandardScaler → SVC(rbf)`.
5. **Оценка** точности функцией `score` на тестовой выборке.
6. **Дополнительные эксперименты:** `class_weight="balanced"`, `LinearSVC`, градиентный бустинг.
7. **Выводы** и предложения по улучшению.

## Результаты

| Модель | Accuracy на тесте (`score`) | Recall класса `>50K` | Время обучения |
|---|---|---|---|
| Базовый уровень (всегда `<=50K`) | 0,752 | 0,000 | — |
| **Логистическая регрессия** | **0,844** | 0,588 | < 1 с |
| **SVM (SVC, ядро RBF)** | **0,842** | 0,568 | ~30 с |
| Логистическая регрессия, `class_weight="balanced"` | 0,806 | 0,830 | < 1 с |
| Линейный SVM (`LinearSVC`) | 0,845 | 0,583 | < 1 с |
| Градиентный бустинг (`HistGradientBoosting`) | 0,866 | 0,631 | ~2 с |

**Кратко:** точность логистической регрессии и SVM практически одинакова (~84%), обе модели на ~9 п.п. лучше базового уровня, переобучения нет. Слабое место обеих: модели находят только ~58% людей с доходом `>50K`. Улучшить результат помогают учёт дисбаланса классов, подбор гиперпараметров, доработка признаков и нелинейные модели (бустинг).

## Как запустить

```bash
pip install -r requirements.txt
jupyter notebook adult_income_logreg_svm.ipynb
```

Ноутбук читает данные из папки `data/`. Если её нет (например, в Google Colab), данные скачиваются напрямую с сайта UCI. Полный прогон занимает около 2 минут, больше всего времени уходит на обучение SVC.

Проверено на Python 3, scikit-learn 1.9, pandas 3.0, matplotlib 3.11, seaborn 0.13.
